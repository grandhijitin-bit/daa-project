## 🎯 Key Topics Covered

1. **The Real-World Narrative:** High-stakes flight check-in scenario (Gate 14, 6 remaining seats).
2. **Why Greedy Fails:** How indivisible group bookings make greedy sorting by price or density lose thousands in revenue.
3. **The 0/1 Knapsack Formulation:** State $dp[i][w]$, Base Cases, and the Bellman Optimality Recurrence equation.
4. **Step-by-Step Matrix Engine:** Complete $5 \times 7$ DP matrix with an interactive backtracking trail revealing the \$900 optimal manifest.
5. **Interactive Classroom Activity ("Beat the Knapsack"):** 60-second countdown game exposing the human intuition trap.
6. **Complexity & Optimization:** $O(N \cdot W)$ pseudo-polynomial time and $O(W)$ 1D array reverse-traversal space optimization.
7. **Cross-Industry Applications:** Air Cargo Belly Freight, Hotel Room Block Allocation, and Cloud Server VM Packing.
